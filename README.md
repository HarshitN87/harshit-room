# Cozy 3D Room Diorama & WebGL Viewer

An interactive 3D WebGL project has been set up in this repository. You can run a local server to view, rotate, and zoom into your room directly in the browser—exactly like Bruno Simon's "My Room in 3D".

---

## 🚀 How to Run the WebGL Project (Bruno Simon Workflow)

All dependencies (`three` and `vite`) have already been installed for you in your folder. To start the local server:

1. Open your terminal in this directory.
2. Run the Vite development server command:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to the local link shown in your console (usually `http://localhost:5173`).
4. **Interact**: Left-click and drag to rotate the room, right-click and drag to pan, and use the scroll wheel to zoom.

---

## 📦 Generated Output Files

This directory contains the following assets generated by the Blender script:

1. **`room_baked_combined.glb`** (2.66 MB):
   - A single, fully-baked GLB file containing the merged mesh of your entire room.
   - The Cycles path-traced lighting, soft shadow maps, ambient occlusion, and neon glows are baked directly into a single 4K texture sheet (`room_baked_combined.png`) for ultimate crispness and sharpness.
   - This file uses a lightweight unlit emission material so it renders in web browsers at a flawless 60 FPS on any device, matching the quality of the Cycles renderer.
2. **`room_render.png`**:
   - A high-resolution path-traced render image of your room from the isometric camera angle.
3. **`room_model.glb` / `room_model.fbx`**:
   - Standard unbaked models containing separate meshes and individual Blender lights (ideal for editing in Blender).
4. **`wood_baked.png`**:
   - The baked 2D texture map of the walnut wood grain, embedded inside `room_model.glb`.
